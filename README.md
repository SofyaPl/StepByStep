## 💡 О проекте

Современные коммерческие планировщики часто перегружены ненужными фичами, сложной иерархией проектов и навязчивыми подписками. **ШагЗаШагом** создан для реальной повседневной жизни:
* Быстро зафиксировать дело и комментарий к нему.
* Открыть день на телефоне, отметить выполненное, отложить или отменить.
* Настроить регулярные приёмы лекарств, тренировки, оплату счетов или дни рождения.
* Хранить данные у себя и синхронизировать с обычной **Google Таблицей**, доступной только вам.

## ✨ Ключевые возможности

### 1. 📅 Фокус на день (Day-by-Day)
* **Горизонтальная лента дней (`DateStrip`)**: быстрый скролл, подсветка сегодняшнего дня, индикаторы количества задач на каждый день.
* **Сортировка по завершенности**: выполненные дела автоматически опускаются в самый низ списка, освобождая визуальное пространство для актуальных задач.
* **Фильтры по статусам**:
  * **Все** — полный список дня;
  * **В плане** — задачи, ожидающие выполнения;
  * **Сделано** — завершенные дела;
  * **Отменено** — отмененные задачи и пропущенные эпизоды циклов.
* **Прогресс-бар дня**: наглядная шкала продуктивности в процентах.

### 2. 🔄 Умные циклические задачи (логика Todoist / LeaderTask)
Регулярные дела часто ломаются в стандартных трекерах, создавая стресс из-за «долгов». В **ШагЗаШагом** этот процесс продуман до мелочей:

* **Гибкие режимы повтора**:
  * *Каждый день*
  * *Каждые N дней* (через 1 день, через 2 дня, через 5 дней — идеально для курсов медикаментов, уколов, полива растений)
  * *По дням недели* (например: только пн, ср, сб)
  * *Ежегодно* (дни рождения, годовщины, регулярные платежи)
  * *Ограничение по сроку* (например, принимать лекарство ровно 4 недели) или бессрочно.
* **Принцип «Без снежного кома долгов»**:
  Если вы пропустили ежедневную зарядку вчера, сегодня приложение **не заставляет делать её 2 раза**!
  * На сегодня вы получаете ровно одну сегодняшнюю задачу.
  * Вчерашняя невыполненная задача помечается как **«Пропущен эпизод» (`missed`)**, не засоряя план на сегодня.
  * При выполнении сегодняшнего эпизода все предшествующие долги этой серии закрываются автоматически.
* **Управление сериями**:
  * В любой момент можно остановить цикл начиная с текущего дня (без раскопок по истории).
  * Редактирование регулярности (можно превратить разовую задачу в цикл или поменять расписание).
  * Выбор при удалении: удалить только этот день, остановить будущие или стереть весь цикл целиком.

### 3. ⏰ Умные просроченные задачи
* Если вы не выполнили **разовую** задачу, она не исчезает: сверху появляется янтарная плашка с предложением в один клик перенести её «На сегодня».
* Для циклических задач система сама понимает, есть ли сегодня плановый эпизод, и не спамит переносами.

### 4. ☁️ Бесплатная личная синхронизация (Google Таблицы)
* **Local-First архитектура**: всё сохраняется в браузере телефона мгновенно (`localStorage`), приложение летает даже в метро без связи.
* **Google Apps Script API**: бесплатный мини-бэкенд, разворачиваемый в вашей собственной учётной записи Google за 2 минуты (код встроен прямо в настройки приложения).
* **Двунаправленная синхронизация**:
  * Изменения в приложении отправляются в таблицу автоматически (с мягким дебаунсом в 3 секунды).
  * Правки, внесённые руками прямо в строки Google Таблицы, корректно подтягиваются на все ваши устройства.
  * **Tombstone-механизм**: надёжная защита от «воскрешения» удалённых задач после синхронизации.

### 5. 📱 Настоящее мобильное приложение (PWA)
* Устанавливается как независимое приложение на Android (WebAPK) и iOS (Safari Home Screen).
* Работает на весь экран без рамок и адресной строки браузера.
* **Автоматическое фоновое обновление**: при возвращении в приложение сервис-воркер проверяет свежую версию и подтягивает её незаметно.
* Встроенная кнопка принудительного обновления и очистки кэша в настройках.
* Резервное копирование и восстановление всей базы задач в один клик через JSON.

## 📲 Как установить на телефон

### 🤖 Android (Google Chrome / Яндекс Браузер)
1. Откройте **[https://sofyapl.github.io/StepByStep/](https://sofyapl.github.io/StepByStep/)**.
2. Нажмите на три точки в правом верхнем углу браузера (`⋮`).
3. Выберите **«Установить приложение»** (или «Добавить на главный экран»).
4. Нажмите **Установить**. Иконка «ШагЗаШагом» появится на рабочем столе и будет запускаться как самостоятельная программа.

### 🍏 iOS (Safari)
1. Откройте ссылку в браузере **Safari**.
2. Нажмите кнопку **«Поделиться»** (иконка квадратика со стрелкой вверх в нижней панели).
3. Прокрутите список вниз и выберите **«На экран "Домой"»**.
4. Нажмите **Добавить**.

## ⚙️ Настройка синхронизации с Google Таблицей

1. Откройте [Google Sheets](https://sheets.new) и создайте новую таблицу.
2. В верхнем меню выберите: **Расширения** (*Extensions*) → **Apps Script**.
3. В приложении «ШагЗаШагом» нажмите на **шестерёнку (Настройки)** → кнопка **«Скопировать готовый код для Google Apps Script»**.
4. Вставьте скопированный код в редактор Apps Script и нажмите **Сохранить (`Ctrl + S`)**.
5. Нажмите **Развернуть** (*Deploy*) → **Новое развертывание** (*New deployment*):
   * Тип: **Веб-приложение** (*Web app*);
   * Кто имеет доступ (*Who has access*): **Все** (*Anyone*).
6. Скопируйте полученный URL веб-приложения, вставьте в поле настроек «ШагЗаШагом» и нажмите **«Сохранить адрес»**.
7. Включите галочку **«Автоматически синхронизировать при изменениях»**.

## 💻 Локальная разработка

Для запуска и доработки проекта на своём компьютере:

```bash
# Клонировать репозиторий
git clone https://github.com/SofyaPl/StepByStep.git
cd StepByStep

# Установить зависимости
npm install

# Запустить локальный сервер разработки
npm run dev

# Проверить сборку
npm run build
```
